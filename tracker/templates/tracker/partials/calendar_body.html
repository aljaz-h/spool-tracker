{% comment %} align-items:stretch can't express "sidebar always matches cal-main's height exactly, whichever is naturally taller" - stretch only grows the shorter item up to the taller one's own content height, so a long agenda list just dragged the whole row (and cal-main with it) down to its own height instead of getting capped, while a short one left empty space below a cal-main-sized box instead of shrinking to match. Explicitly copying cal-main's rendered height onto the sidebar's own height (JS, via ResizeObserver so month navigation/content swaps keep it in sync) pins the sidebar to cal-main in both directions - overflow-y-auto then handles a longer agenda list by scrolling inside that fixed height instead of growing past it. No-ops below the lg: breakpoint, where they stack instead of sitting side by side. {% endcomment %}
