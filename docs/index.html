Quick start

The whole install — no separate app-server setup.

git clone https://github.com/aljaz-h/spool-tracker.git
cd spool-tracker
./setup.sh   # or .\setup.ps1 on Windows

Writes a working .env (random secret key + DB password, prompts for your hostname) and brings the stack up. See the full README for manual configuration, Trakt/Simkl setup, and deploying without cloning the repo.
