Features

Everything a household tracker needs

No accounts to pay for, no data leaving your own server.

📊

Dashboard

Continue watching, up next, watchlist, and personalized recommendations — one page, no digging.

🎬

Movies & TV / Anime

Trending, popular, upcoming, and top rated — live from TMDB, with trailers, media galleries, and Watching/Watchlist/History tabs.

📅

Calendar

New episodes, season premieres, and movie releases synced nightly for anything you're tracking.

📋

Lists

Shared and private lists, plus "Surprise me" to jump to a random title from your watchlist.

📈

Stats

Watch streaks, genre/year breakdown, an activity heatmap, achievement badges, and taste compatibility with other profiles.

🎁

Recommend to a housemate

Send a title to another profile — including as an anonymous "mystery" recommendation.

🎌

Anime enrichment

Score, studio, source, and filler/recap badges from MyAnimeList, with automatic season-numbering reconciliation against TMDB.

📰

Household activity feed

A day-grouped timeline of everyone's watches, binges, and list activity, with a leaderboard.

🔄

Trakt / Simkl / Nuvio sync

OAuth or email/password connect with a daily background sync, or import a CSV export with column-mapping and a preview step.

💾

Automatic backups

Scheduled, per profile, to a server folder, WebDAV (Nextcloud/NAS), Google Drive, or Dropbox — plus a one-off full export/import.

🔐

Two-factor authentication

TOTP via any authenticator app, QR or manual setup, and one-time backup codes.

🔌

Scrobble & Reports API

A generic webhook for any player or script, plus a read-only API for external tools like spool-wrapped.

👥

Multiple profiles

Every household member gets their own history, lists, and stats on one shared instance.

🐳

Docker Compose

Five containers — app, worker, scheduler, Postgres, Redis. One command to run it all.

Get started

Quick start

The whole install — no separate app-server setup.

bash 
git clone https://github.com/aljaz-h/spool-tracker.git
cd spool-tracker
./setup.sh   # or .\setup.ps1 on Windows

Writes a working .env (random secret key + DB password, prompts for your hostname) and brings the stack up. See the Quick start guide for manual configuration, Trakt/Simkl setup, and deploying without cloning the repo.
